# 手で確かめる項目（dictation）

キー入力・貼り付け・トレイ・自動起動は自動テストにできないので、動作に関わる変更のあとに手で確かめる。
`pwsh scripts\install.ps1` で入れ替えてから行う。

## 入力

| # | 場面 | 操作 | 期待する結果 |
|---|---|---|---|
| 1 | ブラウザ（ChatGPT など） | 入力欄で Ctrl+Win を押して話し、離す | 開始・終了の音が鳴り、認識した文が入る。クリップボードは元のテキストに戻る |
| 2 | VS Code | 同上 | 同上 |
| 3 | メモ帳 | 同上 | 同上 |
| 4 | Windows Terminal | 同上 | 同上 |
| 5 | 管理者権限のアプリ | 同上 | 貼り付けられない（Windows の制限）。結果はログに残る |
| 6 | 認識中に別のウィンドウへ切り替える | 離した直後に Alt+Tab | 貼り付けず、失敗の音が鳴る。結果はクリップボードに残る |
| 7 | 短く押す | Ctrl+Win を一瞬だけ押す | 何も起きない（0.3秒未満は捨てる）。スタートメニューも開かない |
| 8 | Windows のショートカット | Ctrl+Win+→ | 録音を取り消し、仮想デスクトップが切り替わる |
| 9 | 押す順番 | Win → Ctrl の順に押す | Ctrl → Win と同じように録音される |
| 10 | Win を離したとき | 録音のあと、Win を最後に離す | スタートメニューが開かない |

## 異常時

| # | 場面 | 操作 | 期待する結果 |
|---|---|---|---|
| 11 | マイクを抜く | Focusrite を外して Ctrl+Win | 失敗の音が鳴る。挿し直すと、次の操作は普通に効く |
| 12 | speechcpp が止まっている | サービスを止めて話す（確かめたら元に戻す） | アイコンが30秒以内に灰色になり、話すと失敗の音が鳴る。サービスが戻ると白に戻る |
| 13 | スリープから復帰する | スリープ → 復帰 | そのまま使える（ログに「フックを入れ直します」） |
| 14 | 画面ロックを解除する | Win+L → 解除 | そのまま使える |

## トレイ・起動

| # | 場面 | 操作 | 期待する結果 |
|---|---|---|---|
| 15 | アイコンの色 | 待機 → 録音 → 認識 | 白 → 赤 → 黄 → 白 |
| 16 | メニュー | 右クリック | 状態（例:「待機中（speech.cpp 接続中）」）が出る |
| 17 | 設定・ログ | 「設定ファイルを開く」「ログのフォルダを開く」 | それぞれ開く |
| 18 | 自動起動 | 「ログオン時に起動」にチェック → サインアウト・サインイン | ログオン後にアイコンが出る。チェックを外すと出なくなる |
| 19 | 終了 | 「終了」 | アイコンが消え、プロセスが終わる |
| 20 | 入れ替え | 起動中に `install.ps1` | 動いていたものが終わり、新しい版が起動する。アイコンの残骸が残らない |
| 21 | 二重起動 | `bin\mozu-dictation.exe` をもう一度起動 | 何も起きない（1つのまま） |
